# 规则验证阶段性判断标准

- 去重后信号样本：108
- 默认目标（10日最高收盘≥15%）全样本胜率约 0.3981
- 涨停子集约 0.5152

## 关键结论

1. **15%/10日 + 宽松过滤（大涨≥5%+放量1.2+主力累计>0）无法达到80%**，实测约40%。
2. **涨停日 + 10日主力累计>1亿** 是当前最稳的提升项，约50%~53%，仍远低于80%。
3. 把成功标准降到 **10日最高收盘≥10%**，部分收紧组合可到 **60%~70%**；≥80%仍需更强条件或换成功定义（如≥8%或含盘中最高价）。
4. **过度放量（≥1.5）反而更差**；温和放量 1.2~1.5 更好——疑似脉冲兑现后乏力。
5. **“近5资金≥前5×1.5”单独并不优**；更关键的是涨停本身 + 累计主力规模。

## 建议冻结的观察池标准（产品用）

### 硬条件
- 市值 > 100亿；非ST；非北交
- 信号日涨停（主板≥9.7%，创业/科创≥19.5%）
- 信号前10日主力累计净流入 > 0，且 **> 1亿**（或 ≥ 市值×0.5%）
- 近5日均量 / 前5日均量 ∈ **[1.2, 1.6]**（拒绝脉冲假放量）

### 重点池加分
- 近5主力 ≥ 前5主力（加速）
- 市值 100~800亿（太大票弹性不足）
- 10日主力 / 市值 ≥ 0.5%

### 成功预期（对外口径）
- **不宜承诺 10日+15% 且胜率≥80%**
- 更现实：观察池目标改为 **10日最高收盘≥8%~10%**，或把15%作为“超额”而不是入池成功标准
