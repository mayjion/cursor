# 最终判断标准（T+1 最低价口径）— 已产品化

配置：`config/limitup_board.yaml`  
代码：`app/limitup/` + `GET /api/boards/limitup` + Web `/limitup` + App `/limitup`

## 交易口径

- 信号日：涨停日
- 买入叙事：次日最低价
- 成功：含买入日共10个交易日最高价相对入场价 ≥ 目标涨幅
- 市值：>100亿（不设上限）

## 分池

| 池 | 条件 | 主目标 |
|---|---|---|
| 观察池 | 10日主力/市值 ≥0.5% | ≥10%（底线8%） |
| 重点池 | 10日主力/市值 ≥0.8% | ≥10%（底线8%） |

硬条件：涨停、市值>100亿、非ST/北交、前10日主力累计>0、放量比≥1.1、剔脉冲假放量。
